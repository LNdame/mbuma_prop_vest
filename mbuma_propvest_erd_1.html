Key design decisions
  • net_monthly_rent = gross_monthly_rent − operating_expenses_monthly. Store it as a persisted computed column or recalculate on save — never trust a stale value for yield calculations
  • projected_yield_pct = (net_monthly_rent × 12) / purchase_price × 100. Mark it computed in Prisma and recalculate whenever rent or expenses change
  • operating_expenses_monthly should cover rates & taxes, levies, insurance, and property management fees — document the breakdown in a separate property_expense_breakdown JSONB column if needed
  • loan_amount / loan_interest_rate — include when the property is partially debt-financed; used to calculate the actual distributable cash after debt service
  • bank_account_number on investor_profiles should be encrypted at rest (use pgcrypto or application-level AES-256)
  • audit_log is append-only — never grant UPDATE or DELETE on this table, even to admins
  • funded_amount on properties is a denormalised sum — update via trigger or in the same transaction as a pledge status change
  • distribution_lines.withholding_tax — South Africa currently does not mandate REIT-style withholding for all structures, but include the field for future use
  • All monetary values use decimal(15,2) — never float
  • All timestamps use timestamptz (timezone-aware) — store in UTC, display in SAST
